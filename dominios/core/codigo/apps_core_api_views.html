apps.core.api.views

Views responsáveis pelos endpoints da aplicação Core.

Disponibiliza endpoints para verificação de saúde da aplicação, autenticação, gerenciamento de tokens, recuperação de senha e gerenciamento de anexos.

class apps.core.api.views.AlterarSenhaView(**kwargs)[código-fonte]

Base: APIView

Disponibiliza o endpoint para alteração da senha do usuário.

Valida o token de recuperação e, caso seja válido, solicita a alteração da senha do usuário no CoreSSO.

class apps.core.api.views.AtualizarTokenView(**kwargs)[código-fonte]

Base: TokenRefreshView

Disponibiliza o endpoint de atualização do access token.

Antes de delegar a atualização ao fluxo padrão do Simple JWT, valida o refresh token e verifica se o usuário associado ainda está autorizado no CoreSSO.

post(request: Request, *args: Any, **kwargs: Any) → Response[código-fonte]

Valida o refresh token e solicita a renovação da autenticação.

O refresh token é validado e o usuário associado é consultado. Em seguida, verifica-se se o usuário continua autorizado no CoreSSO. Caso esteja válido, a implementação herdada de TokenRefreshView gera o novo access token.

Parâmetros:

  • request (Request) – Requisição HTTP contendo o refresh token.

  • *args (Any) – Argumentos posicionais recebidos pela view base.

  • **kwargs (Any) – Argumentos nomeados recebidos pela view base.

Retorna:

Resposta HTTP contendo o novo access token ou um erro

de autenticação.

Tipo de retorno:

Response
