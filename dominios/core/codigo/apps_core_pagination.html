apps.core.pagination

Classes de paginação compartilhadas pelos endpoints da API.

class apps.core.pagination.PaginacaoPadrao[código-fonte]

Base: PageNumberPagination

Define a configuração padrão de paginação das listagens.

As respostas utilizam 10 registros por página por padrão, permitem que o cliente solicite outro tamanho e limitam a página a 100 registros.

O valor all no parâmetro page_size desabilita a paginação para a requisição atual.

get_page_size(request: Request) → int | None[código-fonte]

Obtém a quantidade de registros que deverá compor a página.

Quando o parâmetro page_size possui o valor all, a paginação é desabilitada para a requisição. Para os demais valores, o método utiliza a implementação padrão do Django REST Framework, incluindo as regras de limite configuradas na classe.

Parâmetros:

request (Request) – Requisição HTTP recebida pela API.

Retorna:

Quantidade de registros por página ou None para desabilitar a paginação.

Tipo de retorno:

int | None

max_page_size = 100
page_size = 10
page_size_query_param = 'page_size'
