apps.core.exceptions

Exceções customizadas utilizadas por toda aplicação.

Define exceções específicas para representar falhas de autenticação, integração, validação de dados, tokens, envio de e-mails e processamento de arquivos.

exception apps.core.exceptions.AnexoArquivoError(title: str, detail: str)[código-fonte]

Base: Exception

Indica uma falha relacionada ao processamento de arquivos.

Armazena informações estruturadas para permitir que as camadas superiores retornem uma mensagem apropriada ao cliente.

exception apps.core.exceptions.CepInvalidoError[código-fonte]

Base: ValueError

Indica que um CEP não atende ao formato esperado.

exception apps.core.exceptions.CnpjInvalidoError[código-fonte]

Base: ValueError

Indica que um CNPJ não atende ao formato esperado.

exception apps.core.exceptions.EmailInvalidoError[código-fonte]

Base: Exception

Indica que um endereço de e-mail possui formato inválido.

exception apps.core.exceptions.EnvioEmailError(title: str, detail: str)[código-fonte]

Base: Exception

Indica uma falha durante o envio de e-mail.

Armazena informações estruturadas para apresentação do erro pela camada responsável pelo tratamento da exceção.

exception apps.core.exceptions.FalhaAutenticacaoError[código-fonte]

Base: Exception

Indica uma falha durante o processo de autenticação.

exception apps.core.exceptions.InternalError[código-fonte]

Base: Exception

Indica uma falha interna não tratada pela aplicação.

exception apps.core.exceptions.LinkRastreioInvalidoError[código-fonte]

Base: ValueError

Indica que um link de rastreamento não atende ao formato esperado.

exception apps.core.exceptions.SmeIntegracaoError[código-fonte]

Base: Exception

Indica uma falha na integração com serviços da SME.

exception apps.core.exceptions.TelefoneInvalidoError[código-fonte]

Base: ValueError

Indica que um telefone não possui a quantidade esperada de dígitos.

exception apps.core.exceptions.TokenInvalidoError(title: str, detail: str)[código-fonte]

Base: Exception

Indica um problema relacionado à validação ou processamento de token.

Armazena um título e uma descrição destinados a serem utilizados pelas camadas responsáveis pelo tratamento e apresentação do erro.
