apps.core.storage

Funções utilitárias para configuração do storage privado no MinIO.

apps.core.storage.get_private_storage() → MinioBackend[código-fonte]

Cria o backend de armazenamento privado do MinIO.

O backend utiliza o bucket definido em MINIO_BUCKET_NAME e o storage configurado como default

Retorna:

Instância do backend do MinIO configurada para o

armazenamento privado.

Tipo de retorno:

MinioBackend
