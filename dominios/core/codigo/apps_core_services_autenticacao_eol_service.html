apps.core.services.autenticacao_eol_service

Serviços responsáveis pela autenticaçãoe integração com o EOL/CoreSSO.

Este módulo centraliza as operações necessárias para autenticar usuários no serviço EOL, consultar dados funcionais, sincronizar informações do usuário local e realizar operações relacionadas à senha no CoreSSO.

O fluxo de autenticação também é responsável pela geração dos tokens JWT utilizados pela aplicação após a autenticação bem-sucedida.

class apps.core.services.autenticacao_eol_service.AutenticacaoEOLService[código-fonte]

Base: object

Serviço para autenticação de usuários no EOL.

O serviço é responsável por coordenar a comunicação com o EOL/CoreSSO e integrar os dados retornados pelo serviço externo com os usuários da aplicação.

Entre as operações disponibilizadas estão:

  • autenticação de credenciais no EOL;

  • verificação da existência de usuários no CoreSSO;

  • consulta de cargos funcionais;

  • consulta de dados funcionais do usuário;

  • sincronização do usuário local;

  • geração de tokens JWT;

  • alteração de senha no CoreSSO;

  • atualização da senha do usuário na aplicação.

classmethod alterar_senha_no_coresso(login: str, nova_senha: str) → None[código-fonte]

Altera a senha do usuário e invalida o token de recuperação.

Monta os dados necessários para a requisição à API do CoreSSO e delega a alteração da senha ao repositório de integração. Após uma alteração bem-sucedida, invalida o token de recuperação de senha associado ao usuário.

Parâmetros:

  • login (str) – Login do usuário cuja senha será alterada

  • nova_senha (str) – Nova senha que será definida para o usuário.

Levanta:

  • FalhaAutenticacaoError – Levantada quando ocorre uma falha de autenticação durante a alteração da senha no CoreSSO.

  • SmeIntegracaoError – Levantada quando ocorre uma falha na comunicação ou no processamento da requisição pela API de integração do SME.

classmethod autentica(login: object, senha: object) → dict[str, Any][código-fonte]

Realiza a autenticação de um usuário no serviço EOL da SME.

O método valida as credenciais informadas, monta a requisição para o endpoint de autenticação, envia a solicitação ao serviço externo e processa a resposta retornada.

Parâmetros:

  • login (object) – Identificador do usuário (RF ou CPF).

  • senha (object) – Senha utilizada para autenticação.

Retorna:

Dados retornados pelo EOL após a autenticação

bem-sucedida.

Tipo de retorno:

dict[str, Any]

Levanta:

  • FalhaAutenticacaoError – Caso o login ou a senha sejam inválidos ou as credenciais não atendam às validações de entrada.

  • SmeIntegracaoError – Caso ocorra erro de comunicação, timeout, indisponibilidade do serviço ou qualquer falha retornada pela API do EOL.

  • InternalError – Caso ocorra um erro interno ou de configuração da aplicação.

classmethod login(login: object, senha: object) → dict[str, Any][código-fonte]

Realiza o fluxo completo de login da aplicação.

Autentica as credenciais no EOL e, após a autenticação bem-sucedida:

  1. obtém o registro funcional retornado pelo EOL;

  2. consulta o cargo do servidor;

  3. consulta os dados funcionais do usuário;

  4. sincroniza o usuário com a base local;

  5. gera os tokens JWT da aplicação;

  6. combina os dados locais e funcionais na resposta final.

Parâmetros:

  • login (object) – Identificador(RF ou CPF) utilizado para autenticação no EOL.

  • senha (object) – Senha utilizada para autenticação.

Retorna:

Dados da sessão autenticada, contendo:

  • refresh: Token JWT de renovação.

  • access: Token JWT de acesso.

  • access_expires_in: Tempo de validade do access token,

    em segundos.

  • refresh_expires_in: Tempo de validade do refresh token,

    em segundos.

  • usuario: Dados do usuário sincronizado, acrescidos das

    informações de diretoria regional e unidade educacional.

Tipo de retorno:

dict[str, Any]

Levanta:

  • FalhaAutenticacaoError – Se as credenciais forem inválidas.

  • SmeIntegracaoError – Se ocorrer falha na comunicação ou na integração com o EOL/CoreSSO.

  • InternalError – Se ocorrer erro interno ou problema de configuração durante o processo.

classmethod usuario_existe_no_coresso(login: str) → bool[código-fonte]

Verifica se um usuário está cadastrado no CoreSSO.

Realiza uma requisição à API de integração do CoreSSO para verificar se o usuário identificado pelo RF ou CPF informado já possui cadastro no sistema.

Parâmetros:

login (str) – login: RF (7 dígitos) ou CPF (11 dígitos) do usuário.

Retorna:

True se o usuário existir no CoreSSO (HTTP 200);

caso contrário, retorna False.

Tipo de retorno:

bool
