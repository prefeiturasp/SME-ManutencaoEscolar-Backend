apps.empresa.services.responsavel_service

Serviços de Responsavel Técnico.

class apps.empresa.services.responsavel_service.ResponsavelTecnicoService(repository: ResponsavelTecnicoRepository | None = None, anexo_service: AnexoResponsavelTecnicoService | None = None)[código-fonte]

Base: object

Orquestra as regras de negócio relacionadas a Responsavel Técnico.

bulk_criar(dados_lista: list[dict[str, Any]]) → list[dict[str, Any]][código-fonte]

Cria múltiplos responsáveis e retorna seus dados serializados.

Registra o usuário logado como responsável pela criação.

Parâmetros:

dados_lista – Lista de dicionários com os dados dos responsáveis técnicos a serem criados.

Retorna:

Lista de dados serializados dos responsáveis técnicos criados.

Levanta:

ValidationError – Se já existir um responsável técnico do mesmo tipo cadastrado para a mesma empresa.

remover(responsaveis: list[ResponsavelTecnico], usuario: Usuario | None = None) → None[código-fonte]

Exclui fisicamente os anexos e logicamente os responsáveis.

Parâmetros:

  • responsaveis – Instâncias dos responsáveis técnicos a remover.

  • usuario – Usuário responsável pela exclusão.

sincronizar(empresa_id: int, dados_lista: list[dict[str, Any]], usuario: Usuario | None = None) → list[dict[str, Any]][código-fonte]

Sincroniza os responsáveis técnicos de uma empresa.

Faz o upsert usando o uuid como chave: os itens com uuid são atualizados no registro correspondente (mesmo que o tipo tenha mudado), os itens sem uuid são criados e os responsáveis existentes que não constam na lista são removidos.

Parâmetros:

  • empresa_id – ID da empresa dona dos responsáveis.

  • dados_lista – Lista de dicionários com os dados de cada responsável técnico informado. Os itens que representam um responsável já existente devem conter o seu uuid.

  • usuario – Usuário logado responsável pela alteração.

Retorna:

Lista de dados serializados dos responsáveis técnicos resultantes, na mesma ordem de dados_lista.

Levanta:

ValidationError – Se um uuid informado não pertencer a um responsável técnico da empresa.
