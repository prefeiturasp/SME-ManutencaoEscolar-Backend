Atualiza múltiplos responsáveis técnicos existentes.

Cada dicionário deve conter a chave id identificando o registro a ser atualizado; os demais campos são aplicados na instância.

Parâmetros:

dados_lista (list[dict[str, Any]]) – Lista de dicionários com o id e os campos de cada responsável técnico a atualizar.

Retorna:

Dados serializados dos responsáveis

técnicos atualizados.

list[dict[str, Any]]
